# Hi, I'm Dylan Siney

I'm currently preparing for the FIT Cybersecurity Apprenticeship Programme. I set up this GitHub to document the home labs I'm building and to keep track of what I'm learning along the way. 

My goal right now is to get hands-on with defensive security. I want to see how actual attacks look in system logs instead of just reading the theory behind them.

### What I'm working on right now
- **SOC / SIEM Home Lab:** I repurposed an old desktop into an Ubuntu server running Wazuh. I'm using it to monitor intentionally vulnerable web apps (like OWASP Juice Shop) and track the logs when I run simulated attacks against them.
- **Offensive vs. Defensive basics:** Learning how common vulnerabilities like SQL injection actually work, and more importantly, how to spot them happening in real time.

### Stuff I've been using
- **OS:** Linux (Ubuntu Server mostly), Windows
- **Core Tools:** Wazuh SIEM, Docker, basic Bash/Command Line
- **Concepts:** Log analysis, reading alerts, basic incident reporting
